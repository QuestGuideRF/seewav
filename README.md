# SeeWav

![Пример визуализации](./seewav.png)

SeeWav — компактная CLI-утилита на Python, которая превращает аудиофайл в MP4-анимацию волновой формы. Проект удобен для визуализации музыки, подкастов, демо-треков и коротких роликов для публикации.

## ✨ Особенности
- Создаёт MP4-анимацию волны из обычного аудиофайла.
- Поддерживает настройку цвета, количества столбцов, частоты кадров и разрешения.
- Умеет работать со стерео и раздельно оформлять второй канал.
- Позволяет ограничивать длительность ролика и начинать рендер с нужного момента.
- Использует `ffmpeg`, поэтому легко встраивается в существующий медиапайплайн.

## 🚀 Быстрый старт
### Требования
- Python 3.7 или новее
- установленный `ffmpeg` с поддержкой `libx264` и `aac`

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск
```bash
python seewav.py input.wav out.mp4
```

## 📁 Структура проекта
- `seewav.py` — основной CLI-скрипт и логика генерации анимации.
- `requirements.txt` — список Python-зависимостей проекта.
- `setup.py` — параметры упаковки и регистрация консольной команды `seewav`.
- `seewav.png` — изображение-превью с примером результата.

## 🛠 Использование
### Базовый пример
```bash
python seewav.py demo.wav out.mp4
```

### Кастомизация вида
```bash
python seewav.py demo.wav clip.mp4 --white -B 120 -W 1920 -H 1080 -r 60
```

### Что делает команда
Скрипт читает входной аудиофайл, строит последовательность кадров и сохраняет финальное видео. Если выходной файл не указан, по умолчанию используется `out.mp4`.
